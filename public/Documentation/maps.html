Maps Setup

Configure vector maps, Google Maps, and Leaflet maps without breaking the customer experience.

◇

Vector Maps

SVG-based geography with an appropriate licensed dataset. Typically no API key.

⌖

Google Maps

Requires Google Cloud API configuration and applicable billing.

◎

Leaflet Maps

Client-side interactive map using a tile provider with visible attribution.

Google Maps environment

Provide a restricted browser-facing key. The precise APIs and Map ID depend on the actual map features shipped.

NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=your_key_here
NEXT_PUBLIC_GOOGLE_MAPS_MAP_ID=your_map_id_here

Leaflet and tile providers

Follow tile server policies, use valid attributions and make production tile URLs configurable. Public community tiles should not be treated as guaranteed commercial infrastructure.

Graceful setup states

Missing credentials

Show a clear provider setup state instead of an empty map.

Provider unavailable

Use useful error copy and available retry actions without hiding provider errors.

Keep your data safe

Do not put server credentials in browser code. Restrict browser APIs by allowed referrers and APIs.
