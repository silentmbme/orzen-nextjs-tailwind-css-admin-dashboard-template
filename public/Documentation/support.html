Frequently asked questions

Is the documentation built with Next.js?

No. This documentation package contains static HTML, CSS and JavaScript, and can be hosted separately.

Does the Google Maps demo need a key?

Yes, if the purchased template uses the actual Google Maps JavaScript API. See Maps Setup.

Can I change colors and branding?

Yes. Use the shipped project's theme tokens and shared components. See Customization.

Do I need to create my own backend?

Many template screens use demonstration data. Integrate your own authentication, databases and APIs as needed.
