Deployment

Build, verify, and deploy the Next.js application using your selected hosting environment.

Production checklist

Run your checks

Execute the scripts that exist in package.json. Address build and type errors before delivery.

Review environment variables

Configure external API credentials on your host. Public browser keys must have provider restrictions.

Build the application

Run your configured production build and inspect output for warnings.

Test your deployed routes

Check direct URL loading, page transitions, both themes, charts and map configuration states.

npm run build
npm run start

Deployment options

TargetConsiderations
Next.js-capable managed hostSupports required Next.js server features and env vars
Node serverReverse proxy, process manager, TLS and runtime versions
Static hostingOnly if your actual route and feature set supports static export
Important

Do not assume Orzen Admin is fully static-exportable. Confirm App Router features and integrations before choosing a static hosting target.
