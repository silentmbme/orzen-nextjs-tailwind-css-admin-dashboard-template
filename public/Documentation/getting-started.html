Getting Started

Get Orzen Admin running locally and understand the first configuration steps.

Prerequisite

Use the Node.js version supported by your actual Next.js release and the package manager indicated by your repository lockfile. The commands below use npm as an example.

Quick installation

Unzip the source package

Open the Next.js source project in your preferred editor.

Install dependencies

From the project root, install packages.

Configure environment

Copy the provided environment example if included. Enable optional integrations separately.

Start developing

Run the development script and open the address shown in your terminal.

npm install
npm run dev

Prepare a production build

npm run build
npm run start

Confirm these commands against package.json. Other scripts, deploy targets or static export restrictions may apply.
