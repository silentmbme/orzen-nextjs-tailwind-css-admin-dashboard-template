Project Structure

A customer-friendly map of the app architecture and where to make changes.

Recommended organization

The example below describes a typical App Router layout. Match these names to the folders actually shipped with Orzen Admin.

src/
  app/
    (admin)/              # Dashboard routes
    (auth)/               # Authentication layouts
    (marketing)/          # Landing pages, if present
  components/
    ui/                   # Shared primitives
    layout/               # App shell components
  features/               # Feature-level pages and widgets
  lib/                    # Helpers and configuration
public/                   # Static assets

Where to make changes

GoalStart here
Add a dashboardApp Router page + feature module
Change navigationExisting sidebar navigation configuration
Edit button styleExisting shared Button component and tokens
Update dataTyped demo data or your integration layer
Customize authExisting auth layout and shared forms
Keep the project maintainable

Reuse the existing component primitives. Avoid making copies of Button, Card, theme provider or AppShell in every feature.
